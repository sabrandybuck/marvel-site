# The Web of Heroes — Marvel Site

DTU course 02805 (Social Graphs and Interactions) group site — a weekly interactive data story
mining the network of 303 Marvel Comics superheroes on Wikipedia.

Live site: https://sabrandybuck.github.io/marvel-site/

This project is the first hands-on experience with agentic coding tools for all members of our team.

- **Structure, navigation, and visual design** — the dark, card-based
  layout with a shared header/footer and one page per week.
- **Week 1's content** — the written analysis, figures, interactive network view, and data 
  from frozen snapshot organized to match the assignment's structure 
  (what we asked / did / found / what surprised us).

## Structure

```
marvel-site/
├── index.html                     home page / week index
├── css/style.css                  shared styling (DTU02805 design system + Week 1 additions)
├── posts/
│   ├── week-1-marvel-network.html real Week 1 content
│   └── week-2.html … week-8.html  placeholders, ready to fill in
├── data/week1/                    frozen Week 1 dataset (nodes, edges, summary JSON)
├── assets/week1/                  figures generated by analysis/build_week1.py
└── analysis/build_week1.py        standalone analysis script (NetworkX + pandas + matplotlib)
```

## Adding a new week's post

1. Copy `posts/week-1-marvel-network.html` (or one of the `week-N.html` placeholders) as a
   starting template — it already uses the shared header/footer and CSS classes.
2. Update the matching card on `index.html` to link to the new post.
3. Reuse the existing CSS component classes (`.stats-grid`, `.rank-list`, `.figure-grid`,
   `.callout`, etc.) from `css/style.css` rather than introducing new styles, so the whole site
   keeps one visual identity.

## Regenerating the Week 1 analysis and figures

```
cd marvel-site/analysis
python build_week1.py
```

Requires `networkx`, `pandas`, `numpy`, and `matplotlib`. The script reads from `../data/week1/`
and writes figures to `../assets/week1/` and the summary JSON to `../data/week1/week1_summary.json`.
It asserts 303 nodes, 1,784 directed edges, and 17 isolates — the known values from the course
data page — and raises exception if the data or loading logic ever produces something different.

## Data source

`data/week1/week1_nodes.tsv` and `data/week1/week1_edges.tsv` are copies of the frozen Week 1
snapshot (2026-08-26) from the course data page:

- https://sunelehmann.com/socialgraphs2026-web/data/week1_nodes.tsv
- https://sunelehmann.com/socialgraphs2026-web/data/week1_edges.tsv
